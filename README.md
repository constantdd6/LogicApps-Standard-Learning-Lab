# LogicApps-Standard-Learning-Lab

## Overview
This repository is a comprehensive learning lab for Azure Logic Apps Standard, demonstrating key concepts and best practices.

## Topics Covered

### Triggers
- **HTTP Trigger** - Learn how to trigger Logic Apps workflows via HTTP requests
- **Service Bus Trigger** - Understand event-driven workflows using Azure Service Bus
- **Storage Trigger** - Explore blob and queue storage event triggers

### Reliability & Resilience
- **Error Handling** - Implement robust error handling and exception management
- **Scopes** - Organize actions and control flow within Logic Apps
- **Retry Policies** - Configure retry strategies for failed actions

## Getting Started

1. Clone this repository
2. Review the workflow examples organized by topic
3. Deploy to your Azure subscription
4. Explore and experiment with each concept

## Prerequisites

- Azure subscription
- Azure Logic Apps extension for Visual Studio Code
- Basic understanding of Logic Apps workflows
